# 은호당 현공비성 풍수 나침반

집의 좌향(坐向)을 입력하면 현공 비성(玄空飛星) 궁반을 만들어, 쉬운 풀이로 집터의 기본기·방 배치·길방(吉方)을 분석해 주는 웹 풍수 나침반 도구입니다.

중국어(번체) 원본 앱을 한국어로 로컬라이징하고, 애플 Human Interface Guidelines 기준으로 디자인을 재설계했습니다. 풍수 전문 용어는 쉬운 풀이말을 앞세우고 한국 한자음 + 한자를 병기합니다(예: 일백탐랑(一白貪狼), 건궁(乾宮)).

## 사용 방법

정적 웹앱이라 별도 빌드가 없습니다. 로컬에서 간단한 정적 서버로 열면 됩니다.

```bash
# 저장소 루트에서
python -m http.server 8080
```

브라우저에서 `http://localhost:8080/` 을 열면 기기를 자동 감지해 데스크톱은 `compass.html`, 모바일은 `compass-mobile.html` 로 이동합니다. 비밀번호 없이 바로 로드됩니다. 원하는 화면을 직접 열고 싶다면 `compass.html`(데스크톱) 또는 `compass-mobile.html`(모바일 전용) 을 열면 됩니다.

> 파일을 직접 더블클릭(`file://`)으로 열면 모듈 동적 로딩이 막힐 수 있으니, 위처럼 정적 서버로 여는 것을 권장합니다.

## 주요 기능 (7단계 흐름)

1. **방향 측정** — 집이 바라보는 방향(좌향)을 나침반/수동 입력으로 지정
2. **택반(宅盤) 보기** — 집 전체의 현공 비성 궁반 기본기 확인
3. **비성(飛星) 조회** — 방향별 산성/향성 해석과 활용법
4. **길방 찾기** — 재물·인연·문창(文昌) 자리
5. **방 배치** — 대문·방·가구·설비를 9×9 배치판에 표시
6. **종합 평가** — 입력한 자료를 모아 우선순위 조언 제시
7. **유년(流年) 계산** — 올해·이번 달 단기 주의점

## 주역 보조 (주역의 원)

나침반 홈에 주역의 원(https://iching-circle.pages.dev/) 자료를 붙였습니다. 현공 비성 계산은 바꾸지 않습니다.

- 8궁 카드: 후천 괘의 설괘전·가족·몸·동물. 오행은 나침반에 원래 있던 값을 유지합니다.
- 좌향 보조 괘: 향궁을 상괘, 좌궁을 하괘로 겹칩니다. 규칙은 `src/iching-circle.js`의 `HOUSE_HEXAGRAM_STACK` 한 곳입니다. 현공 배반이 아닙니다.
- 오늘의 괘: 서울 날짜를 키로, `crypto.getRandomValues` 거절 샘플링. 64괘와 384효를 따로 저장합니다.
- 64괘 고리: 문왕괘서 1–64를 나침반 0°부터 시계 방향. 탐색 배열이며 복희 원도가 아닙니다.

자료는 `data/`의 JSON입니다. 해석은 검토 전 초안(`review.status = draft`)입니다.

`src/compass-app.js`는 `./dual-star-corpus.json`을 불러 성결 원문에 쓰지만, 이 파일은 저장소에 없습니다. 없으면 그 원문만 비고 나머지 나침반은 그대로 동작합니다.

## 구조

| 경로 | 설명 |
| --- | --- |
| `index.html` | 기기 감지 리디렉션 진입점 (데스크톱→`compass.html`, 모바일→`compass-mobile.html`) |
| `compass.html` | 데스크톱 메인 페이지 (CSS 인라인, JS 모듈 로더) |
| `compass-mobile.html` | 모바일 전용 컴팩트 페이지 (세로형 레이아웃, 동일 7단계 기능) |
| `src/` | 바닐라 JavaScript 모듈 (계산 엔진 + 데이터 + UI) |
| `assets/` | 앱 아이콘 |
| `manifest.webmanifest` | PWA 매니페스트 (모바일 홈 화면 추가 지원) |

## 기술

- 프레임워크/빌드 도구 없는 정적 HTML + 바닐라 JS
- Pretendard 폰트, 뉴트럴 그레이 + 오렌지 액센트 팔레트, 다크 기본 + 라이트 테마
- 본문·버튼·상태 표시 모두 WCAG AA(대비 ≥ 4.5:1) 충족
- 반응형 (모바일/데스크톱), `prefers-reduced-motion` 대응
