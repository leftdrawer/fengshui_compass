# 은호당 현공비성 풍수 나침반

집의 좌향(坐向)을 입력하면 현공 비성(玄空飛星) 궁반을 만들어, 쉬운 풀이로 집터의 기본기·방 배치·길방(吉方)을 분석해 주는 웹 풍수 나침반 도구입니다.

중국어(번체) 원본 앱을 한국어로 로컬라이징하고, 애플 Human Interface Guidelines 기준으로 디자인을 재설계했습니다. 풍수 전문 용어는 쉬운 풀이말을 앞세우고 한국 한자음 + 한자를 병기합니다(예: 일백탐랑(一白貪狼), 건궁(乾宮)).

## 사용 방법

정적 웹앱이라 별도 빌드가 없습니다. 로컬에서 간단한 정적 서버로 열면 됩니다.

```bash
# 저장소 루트에서
python -m http.server 8080
```

브라우저에서 `http://localhost:8080/compass.html` 을 열고 입장 비밀번호를 입력하면 시작됩니다.

> 파일을 직접 더블클릭(`file://`)으로 열면 모듈 동적 로딩이 막힐 수 있으니, 위처럼 정적 서버로 여는 것을 권장합니다.

## 주요 기능 (7단계 흐름)

1. **방향 측정** — 집이 바라보는 방향(좌향)을 나침반/수동 입력으로 지정
2. **택반(宅盤) 보기** — 집 전체의 현공 비성 궁반 기본기 확인
3. **비성(飛星) 조회** — 방향별 산성/향성 해석과 활용법
4. **길방 찾기** — 재물·인연·문창(文昌) 자리
5. **방 배치** — 대문·방·가구·설비를 9×9 배치판에 표시
6. **종합 평가** — 입력한 자료를 모아 우선순위 조언 제시
7. **유년(流年) 계산** — 올해·이번 달 단기 주의점

## 구조

| 경로 | 설명 |
| --- | --- |
| `compass.html` | 메인 페이지 (CSS 인라인, 입장 게이트 + JS 모듈 로더) |
| `src/` | 바닐라 JavaScript 모듈 (계산 엔진 + 데이터 + UI) |
| `assets/` | 앱 아이콘 |
| `manifest.webmanifest` | PWA 매니페스트 (모바일 홈 화면 추가 지원) |

## 기술

- 프레임워크/빌드 도구 없는 정적 HTML + 바닐라 JS
- Pretendard 폰트, 따뜻한 뉴트럴 브라운 팔레트, 다크/라이트 테마
- 본문·버튼·상태 표시 모두 WCAG AA(대비 ≥ 4.5:1) 충족
- 반응형 (모바일/데스크톱), `prefers-reduced-motion` 대응
